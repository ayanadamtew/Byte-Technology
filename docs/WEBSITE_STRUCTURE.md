## 3. Core User Journeys

### Journey A: The Operations / Managing Director Seeking an ERP or Custom System
1. **Entry:** Lands on **Home (`/`)**; reads the headline and sees `Custom Software and ERP Systems` highlighted in the Hero System Blueprint.
2. **Exploration:** Scrolls to **Section 1.4 (Interactive Solution Selector)** and selects *"Centralize internal operations & resource planning"*, seeing how Custom ERP, Cloud Solutions, and IT Consulting connect.
3. **Deep Dive:** Clicks into **Services (`/services#erp`)** to inspect the ERP architectural schematic and deliverables.
4. **Conversion:** Clicks **`Discuss an ERP & Custom Software Project`**, which opens **Contact (`/contact`)** with `Custom software and ERP systems` pre-selected, and sends a structured project brief to `ayanadamtew@gmail.com`.

### Journey B: The Commercial / Product Leader Launching a Web or Mobile Platform
1. **Entry:** Lands on **Home (`/`)** on a mobile or desktop browser; inspects the Bento cards for `01 Web Development`, `02 Mobile Application Development`, and `06 UI/UX Design`.
2. **Validation:** Visits **Approach (`/approach`)** to verify that Byte Technology pairs UI/UX research with scalable engineering rather than delivering disconnected templates.
3. **Conversion:** Uses the **Consultation Intake (`/contact`)** to select `UI/UX design`, `Web development`, and `Mobile application development` and initiates a consultation.

### Journey C: The CIO / Institutional Decision-Maker Evaluating Technical Governance
1. **Entry:** Reviews **About (`/about`)** to understand Byte Technology's mission (*"To Digitalize Ethiopia"*) and commitment to security and maintainability.
2. **Evaluation:** Reviews `04 IT Consulting`, `05 Cloud Solutions`, and `07 AI and Business Automation` on **Services (`/services`)**.
3. **Direct Outreach:** Clicks the direct email link (`ayanadamtew@gmail.com`) in the Contact section to request an executive technology advisory discussion.

## 4. Call-to-Action (CTA) Architecture

To maintain a consultative, high-trust B2B tone, CTAs avoid pushy retail language ("Buy Now", "Sign Up Free") in favor of partnership-oriented actions:

| CTA Tier | Primary Copy | Visual Styling | Destination / Behavior |
| :--- | :--- | :--- | :--- |
| **Global Header CTA** | `Request Consultation` | Solid Byte Navy (`#1A2130`) on light header; Byte Orange (`#FA8112`) on hover | Navigates to `/contact` consultation intake. |
| **Hero Primary CTA** | `Start a Project Conversation` | Solid Byte Orange (`#FA8112`) with crisp white/ink contrast and directional arrow `→` | Navigates to `/contact` consultation intake. |
| **Hero Secondary CTA** | `Explore Our 7 Capabilities` | Warm Alabaster surface with `1px` `#1A2130` structural border | Smooth-scrolls to the 7 Services Bento Matrix or `/services`. |
| **Contextual Service CTA** | `Inquire About [Service Name] →` | Monospace/medium link in Byte Orange (`#FA8112`) inside each service module | Navigates to `/contact?service=[service-slug]` with that capability pre-selected. |
| **Direct Executive CTA** | `Email ayanadamtew@gmail.com` | Interactive copy-to-clipboard + `mailto:ayanadamtew@gmail.com` trigger | Opens default email client or copies address with confirmation feedback. |
